Box Model Assignment: Event Board

Suggested time: 2 hours 100 marks

Build the page shown in target.png from scratch, writing both HTML and CSS. The text and pictures you need are in the content.txt and the img folder. Match the target at a browser width of 1200px, and meet every measurement below. Use DevTools to measure your own work as you go.

You may not use flexbox, grid, float, position, !important or JavaScript. Use class seclectors, and write semantic HTML.
